# 作业时钟

面向六年级至高三学生的 iPad 时间计划与执行陪伴应用。

当前采用 PWA 本地自用方式：首次通过 HTTPS 加载并添加到 iPad 主屏，资源准备完成后日常离线使用。提醒只在打开时运行，回来后刷新计时；不开发微信小程序或后台通知。

完整项目资源纳入统一版本管理，私有仓库为 [caihker/homework-clock](https://github.com/caihker/homework-clock)，当前基线为 **v1.2.4**。目录范围、提交与发布流程见 [版本管理说明](docs/version-management.md)，各版本变化见 [CHANGELOG](CHANGELOG.md)。GitHub用于保存源码和资源，iPad仍通过下面的私有网址更新。

## 运行 Demo

[打开私有在线 Demo](https://homework-clock-demo-caihker.wujiyu2002.chatgpt.site)，可以在 iPad Safari 中访问。

```sh
cd demo
npm start
```

打开终端显示的本地地址，操作说明见 [Demo 说明](demo/README.md)。
