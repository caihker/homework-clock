# v1.5.0 时间手动输入与记事

2026-11-14（北京时间）。本版在阶段 3 基础上补充两项用户需求：时间选择保留十分钟档位并可手动输入；新增不带时间段的「记事」。

## 时间手动输入

- 时间选择弹窗顶部原预览改为可编辑输入框，支持 `HH:MM`（如 `09:07`），也接受一位数小时/分钟与全角冒号。
- 十分钟档位保持不变：点小时/分钟仍按档位选择；手动输入不会被强制取整，任意分钟只要在窗口内即可保存。
- 校验窗口：开始时间 08:00–21:00，结束时间 08:00–21:50；非法或越界输入会留在弹窗并提示，不写回原字段。
- 打开弹窗时优先解析已有时间（旧的非十分钟时间不会被改写），并选中输入内容方便直接覆盖。
- 新增纯函数 `parsePickerInput()`：非法格式、越界、分钟 >59 均返回 null；带 10 项单元测试。
- 网格选择、键盘操作、取消与确认逻辑保持不变；确认时校验输入，非法则不关闭弹窗。

## 记事

- 时间轴末尾新增「记事」区：可给当前日期添加自由文字，不带开始/结束时间，不参与计时、提醒、完成统计与冲突检测。
- 每条记事最多 300 字，支持添加、编辑、删除；编辑弹窗含删除入口，列表内也可直接删除。
- 数据保存在主 state 的 `notes: [{ id, date, text }]`，随本机自动保存；切换日期只看当天记事。
- 「复制这一天」同时复制记事到目标日期（新 id）；「重新体验示例」会清空记事。
- 加载归一化：非法 id/日期/空文本/超长文本会被过滤并计入「部分记录无法读取」；旧数据没有 `notes` 时自动为空列表。
- 备份 schema 增加可选 `notes`，导出/恢复保持无损；旧备份没有记事时恢复为空列表，非法或重复记事会拒绝整份备份。

## 局限

- 截图来自本机 Chrome 无头模式，非 iPad Safari；iPad 原生键盘遮挡、输入法组合与触控仍需真机确认。
- 记事按日期保存，不提供跨日期汇总或提醒；「复制这一天」会复制记事，单条计划复制不会。
- 时间窗口未放宽：仍为 08:00–21:00（结束至 21:50）。
- 本版未改存储版本号；`notes` 为可选新增字段，旧版本读取新数据时会忽略该字段，回退会丢失记事但不影响计划与录音。
