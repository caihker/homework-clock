# 作业时钟 第一版设计文档

版本：v0.1  
日期：2026年11月1日  
状态：产品设计基线，设备限制与后台提醒进入技术验证阶段。

作业时钟是一款面向六年级至高三学生的 iPad 时间计划与执行陪伴应用。学生把语文预习、数学试卷、午饭和游戏安排到具体时间段；应用提醒活动切换，提供可抬头查看的专注时钟，并通过家人的声音和宠物给予适度鼓励。

第一版围绕四件事展开：快速安排今天、看清当前和下一项、按时提醒、完成后简短反馈。学习期间限制其他应用是核心需求，必须验证系统授权、限制生效和解除的完整流程，不能以全屏显示代替设备限制。

## 1 产品目标与范围

### 1.1 已确定的需求

- 保留不同科目的具体作业计划，名称由学生填写，例如语文预习、模拟 AMC 数学试卷。
- 支持学习、生活、娱乐共同组成全天时间表。
- 负责计划时间、执行提醒与完成反馈；无需录入题目或教材内容。
- 学习期间提供防止使用其他应用的专注保护，明确展示实际生效状态。
- 支持家庭录音、家庭暗号和宠物配置，界面简洁、直观、生动。
- 兼顾低龄学生的陪伴需求和高中生对简洁外观的偏好。

### 1.2 第一版功能

| 优先级 | 功能 | 第一版边界 |
| --- | --- | --- |
| P0 | 今日时间轴 | 查看当天及其他日期的安排，突出当前和下一项 |
| P0 | 创建和修改计划 | 名称、开始、结束；支持复制、删除、常用模板与按星期重复 |
| P0 | 专注时钟 | 大字剩余时间、任务名称、结束时间，支持暂离和完成 |
| P0 | 提醒 | 开始、结束、娱乐收尾预告，修改计划后重排提醒 |
| P0 | 时间与完成规则 | 迟开始、暂离、提前完成、延长、冲突、未确认处理 |
| P0 | 专注保护 | 按学习时间段限制应用；授权和设备验证是交付门槛 |
| P0 | 本机保存 | 断网可用，重开恢复计划与计时状态 |
| P1 | 家庭提醒 | 开始、收尾、鼓励三类短录音及一个家庭暗号 |
| P1 | 宠物陪伴 | 一只默认宠物，安静陪伴与简短完成动作，可关闭 |

P0 为可用闭环；P1 在首个家庭试用版本交付。第一版暂缓账号、远程家长端、跨设备同步、拍照识别、AI 自动排程、社交排名、积分商城和复杂宠物养成。统计中的计时记录不等同于学习质量。

### 1.3 验收目标

- 熟悉后新增一项普通计划的目标用时不超过 15 秒，后续通过真实试用检验。
- 首页无需进入详情即可看到当前任务、结束时间和下一项安排。
- 已有模板可以复制到指定日期，冲突保存前可发现。
- 暂离、迟开始和重开应用不会悄悄改变后续计划。
- 无通知权限或无应用限制授权时，界面如实显示能力状态。

## 2 使用场景

以用户提供的一天为首个端到端样例：

| 时间 | 名称 | 类型 | 行为 |
| --- | --- | --- | --- |
| 10:00–12:00 | 语文预习 | 学习 | 开始提醒，专注时钟，结束询问完成情况 |
| 12:30–13:30 | 出去吃午饭 | 生活 | 开始轻提示，不要求打卡 |
| 14:00–15:00 | 游戏时间 | 娱乐 | 开始提示，14:55 收尾预告，15:00 结束提示 |
| 15:30–17:50 | 模拟 AMC 数学试卷 | 学习 | 准备提醒可选，默认整段计时，不强制插入休息 |

未安排的空档保持自由时间，不自动补齐、不记为拖延。游戏结束提醒与限制应用是不同能力；15:00–15:30 没有学习计划时，第一版不会仅因上一段游戏结束自动建立新的禁用时段。

学生负责开始、暂离、确认完成和提出调整。家长负责初次设置、录音及受保护的限制规则；第一版在同一台 iPad 上完成，暂不发送远程消息。

## 3 信息架构与界面

### 3.1 一个主页面和一个专注状态

首页为今日时间轴，点击日期切换其他天。新增、模板和复制从加号进入；右上角齿轮进入设置。当日回顾折叠在时间轴末尾。专注时钟由当前任务进入，不增加独立底部标签。

| 界面 | 主要内容 | 主要操作 |
| --- | --- | --- |
| 今日时间轴 | 日期、当前卡片、下一项、按时间排列的计划、自由空档 | 开始或继续、新增、编辑 |
| 新增与编辑 | 名称、开始、结束；类型快捷选择；更多设置折叠 | 保存、取消 |
| 全屏专注 | 当前任务、大字剩余时间、原定结束时间、真实保护状态 | 完成、暂离 |
| 到点收尾 | 当前任务结束，询问进度 | 完成、还没完成 |
| 家庭设置 | 提醒、声音与暗号、宠物、专注保护、家长设置 | 试听、授权、配置 |

### 3.2 今日时间轴

- 顶部当前卡片展示任务名、开始至结束时间、剩余分钟数。
- 时间轴使用当前时间标线，已结束条目弱化，未确认学习任务保留提示。
- 下一项显示名称、开始时间和距离开始多久；空档不显示运行中的任务。
- 每项提供点击编辑、菜单复制和删除；完成与删除提供撤销入口。
- 支持拖动调整时间，同时保留可点击的时间编辑入口；冲突时不静默覆盖。
- 没有计划时展示“今天还没有安排”和“添加第一项”，不放营销或复杂引导。

### 3.3 新增与编辑

默认必填名称、开始时间、结束时间。类型为学习、生活、娱乐，常用模板可以带入类型、时长和提醒规则。手动创建默认学习，保存前可更改类型。科目为可选项，第一版不要求维护标签或优先级。

更多设置包含科目、重复日期、提醒例外、计时方式、备注和本项保护例外。录音等全局设置默认继承家庭配置。结束时间必须晚于开始时间；第一版每个实例限于同一当地日期，跨日任务提示拆为两项。

重复计划按每周指定星期生成实例。修改或删除时区分“仅这一次”和“本次及以后”；过去记录不被模板修改覆盖。复制到有计划的日期时先预览，禁止重叠后直接保存。整天复制和常用模板比自然语言输入优先开发。

### 3.4 全屏专注

视觉优先级为剩余时间、任务名称、结束时间；当前时刻使用较小字号。普通学习默认显示到分钟，模拟考试可显示秒。横屏充分使用 iPad 显示面积，竖屏保持同一信息顺序。

常驻按钮只有“完成”和“休息 5 分钟”。休息到点自动恢复专注统计，可通过“结束休息”提前恢复；计划倒计时继续，原定结束时间保持不变。延长从收尾页或任务菜单进入；设置、装扮和回顾在专注时收起。宠物只做低频安静动作，无连续点击互动。支持系统文字大小、VoiceOver 和减少动态效果，状态同时使用文字或图标表达。

## 4 时间和执行规则

### 4.1 固定时间段为默认

10:00–12:00 的语文预习，10:20 点击开始时，剩余时间为 100 分钟，仍在 12:00 结束。专注时长从真实开始时刻累计，暂离期间不累计。暂离不推迟计划结束时间，也不解除应用限制。

模拟考试可在更多设置中选择“从开始起计满时长”，例如 140 分钟。启动前显示实际结束时间；若超出预留时段或与下一项冲突，先确认调整。只有计时和保护的新安排均成功保存后才开始；失败则保留原计划，不显示保护已生效。

第一版不强制使用 25 分钟番茄节奏。学习者可自行暂离；自动循环休息暂缓，避免与固定时间表和模拟考试产生两套冲突的时钟。

### 4.2 状态相互独立

| 状态维度 | 取值与含义 |
| --- | --- |
| 计划时间 | 未开始、时段内、已结束，根据当前时间计算 |
| 执行 | 未启动、进行中、暂离、已结束，不从时间到点推断完成 |
| 完成结果 | 未确认、完成、未完成、取消；生活与娱乐使用不适用 |
| 专注保护 | 未配置、未授权、已安排、已授权且已配置、状态待核实、失败 |

到点时停止本段专注累计，学习任务等待学生确认；下一项仍按原时间提醒。错过开始的任务不自动计为已专注。应用重开时由存储的时间锚点恢复，不能从零重新计时。

### 4.3 调整规则

| 情况 | 默认处理 |
| --- | --- |
| 迟开始 | 保留原定结束时间，显示剩余时长 |
| 暂离 | 停止专注累计，计划和保护的结束时间不变 |
| 提前完成 | 记录完成，不提前启动下一项；本段保护默认保留到原定结束 |
| 提前解除保护 | 从家庭设置规定的家长确认入口操作，应用内密码不能代替系统认证 |
| 到点未回应 | 保持未确认，不连续弹窗、不自动勾选完成 |
| 延长 10 分钟 | 空档足够则延长；冲突则提供缩短、另约时间或编辑后续安排 |
| 修改生效中的计划 | 同步更新结束提醒和保护安排，失败时明确提示并保留可追踪状态 |
| 取消或删除 | 取消待发提醒和属于本任务的保护安排，撤销时重新计算 |

提前完成后可以在设备外自由活动。只有家长明确批准或保护时段自然结束，才提前或按时解除本应用设置的限制。第一版不把“完成”按钮直接作为绕过保护的入口。

时间表禁止计划重叠。冲突检测使用开始包含、结束不包含的区间，因此 12:00 结束的任务可与 12:00 开始的下一项相邻。保护按全部有效学习时段合并计算，结束某一任务不能错误解除紧接着的学习限制。

## 5 提醒规则

| 类型 | 默认开始 | 默认收尾 | 完成确认 |
| --- | --- | --- | --- |
| 学习 | 到点一次 | 结束一次 | 需要 |
| 生活 | 到点轻提示 | 默认关闭，可开启 | 不需要 |
| 娱乐 | 到点一次 | 提前 5 分钟预告和结束一次 | 不需要 |

提前准备提醒按需开启。娱乐时段不足 5 分钟时取消提前预告，仅保留结束提醒。同一时刻上一项结束与下一项开始合并提示，避免重复播放。学生已提前完成后取消本项结束询问，保留后续计划提醒。

前台使用页面变化加一次声音，家庭录音替代默认提示音；后台和锁屏使用系统通知。家庭录音如用于自定义通知声音，需转为支持的格式、保存到指定位置并小于 30 秒；第一版录音控制在 3 至 8 秒。提醒呈现仍受通知授权、专注模式、音量等系统设置影响，不承诺后台任意播音或到点强制打开应用。[Apple 本地通知](https://developer.apple.com/documentation/usernotifications/scheduling-a-notification-locally-from-your-app)、[通知声音](https://developer.apple.com/documentation/usernotifications/unnotificationsound)

未授予通知权限时显示“离开应用后暂时无法提醒”，允许稍后配置，不显示设置成功。

创建、编辑、复制、取消、重复例外及完成后都重新计算待发通知。通知使用稳定标识，避免重开应用重复排程。待发请求采用滚动窗口，并在应用启动、回前台和编辑时补排；最终窗口大小与系统限制在技术验证中确定。用户未再次打开应用时，不承诺后台无限补排。

## 6 家庭声音与宠物

家庭声音分为开始、收尾、鼓励三类短录音。建议每条 3 至 8 秒，可试听、重录、删除、调节或静音。设置一个可选家庭暗号，开始时播放或显示，例如“小熊开工”。默认全局继承，不要求每项任务配置。

第一版提供一只默认宠物和显示开关。专注时安静陪伴，完成学习后短暂庆祝，当日结束给出一句具体鼓励，例如“今天确认完成了两项学习安排”。未完成或暂离时不使用责备、惩罚或宠物受伤表现。

家长设置区保护录音管理、限制规则和提前解除等操作。学生可查看、开始、暂离、确认完成及提出调整；保护已配置后，缩短或删除受保护时段、关闭保护、改变其活动类型等能提前释放限制的操作需要家长确认。应用内设置保护与系统 Family Controls 授权分别实现，不宣称完全防绕过。

## 7 专注保护的产品约束

### 7.1 原始目标与交付边界

用户目标是学习期间不能进行 iPad 的其他操作。工程验证拆为两部分：限制干扰应用，以及将设备严格保持在一个应用内。两者能力不同，验收必须分别记录。

主方案验证 Apple 的 Family Controls、Managed Settings 与 Device Activity：在家长或设备使用者授权后，按学习时段设置应用限制并在结束时解除。第一版以家庭首次统一配置的限制范围为准，学习任务继承；家庭外出、午饭和娱乐时段不建立学习限制。

“开始”按钮负责实际计时，保护按已配置的学习时段运行，不因学生没有点击开始就失效。未授权时仍可安排计划和计时，但清楚展示“仅计时，未开启应用限制”。本应用仅解除自身施加的限制，不覆盖系统或其他家庭控制。

引导式访问作为家长手动启动的加强方式验证，不作为普通家庭设备自动进入与自动退出的实现前提。若要求绝对锁定全部系统操作，必须据真机结果确定可支持的设备管理条件；未验证前不承诺完整满足。

### 7.2 必须验证的路径

- 初次授权、拒绝授权、撤销授权以及儿童与个人授权的能力差异。
- 学习开始时应用不在前台，限制能否按计划生效。
- 到点解除、提前完成、连续学习时段、编辑或取消后的限制是否一致。
- 暂离继续保持限制，提前解除需家长确认；保护规则变更后不遗留屏蔽。
- 临时查资料的家长授权入口及恢复规则；第一版不提供学生自行添加允许应用。
- 锁屏、强制退出、设备重启、手动修改时间与时区的表现。
- App Store 分发所需的能力申请、签名及扩展配置。

限制状态只有在相关授权和配置结果可核实时才标记“已授权且已配置”；缺乏可靠状态时标记“状态待核实”，不能用计时开始代替限制生效。是否实际阻止访问通过真机验收确认。应用限制未达标时，专注保护保持未完成状态，记录与原始目标的差异后再决定发布范围。

### 7.3 已核实的系统边界

Family Controls 路线用于屏蔽指定应用、类别或网站，不等于禁止全部系统界面与硬件操作。儿童授权与个人授权分别设计；儿童授权需要家庭共享组的家长或监护人批准，个人授权由设备所有者批准，可以撤销，防绕过能力不同。[Apple Family Controls](https://developer.apple.com/documentation/familycontrols)、[授权方式说明](https://developer.apple.com/videos/play/wwdc2022/110336/)

Family Controls 的主应用和使用相关能力的扩展需要申请对应分发资格。开发环境可运行与 TestFlight 或 App Store 可分发分别验收。[Apple 分发能力申请](https://developer.apple.com/documentation/familycontrols/requesting-the-family-controls-entitlement)

Device Activity 监控区间最短为 15 分钟。因此“再做 10 分钟”、晚开始时剩余不足 15 分钟、以及结束后临时延长的保护，不能直接假定可以创建一个短监控解决。M0 需验证可行的排程方式及异常恢复。若无法可靠覆盖短时段，受保护模式中不提供尚未支持的延长选项，并明确提示；普通计时可继续支持。不得因设置失败而暗中退回无保护状态。[Apple 最短监控时长](https://developer.apple.com/documentation/deviceactivity/deviceactivitycenter/monitoringerror/intervaltooshort)

第 4 节及 A06 中的 10 分钟延长是目标交互，保护部分受此技术门槛约束；实施前据 M0 结果确定最终可选时长，更新文档与验收标准。

## 8 技术方案与数据

### 8.1 建议技术路线

原生 SwiftUI，部署目标暂定 iPadOS 17 及以上；本机数据使用 SwiftData，通知使用 UserNotifications，录音使用 AVFoundation。专注保护通过独立适配层接入系统相关框架及扩展，授权失败不能破坏计划和计时数据。最低系统版本与签名能力在 M0 阶段确认。

产品界面不展示框架名、扩展名或内部错误码。开发日志记录失败阶段，面向学生使用“提醒未开启”“保护尚未生效”等可操作文案。

### 8.2 核心数据

| 数据 | 最小字段 |
| --- | --- |
| 计划实例 | 标识、名称、当地日期、开始与结束、类型、可选科目、计时方式、结果、模板来源 |
| 重复模板 | 标识、名称、当地起止时刻、星期规则、有效日期、默认设置 |
| 专注记录 | 计划标识、开始与结束、暂离片段、结束原因；专注总时长由片段计算 |
| 家庭配置 | 提醒默认值、三类录音引用、暗号、宠物开关、家长设置保护 |
| 保护配置 | 授权状态、受保护范围的系统令牌、计划关联、最后配置结果 |
| 调度记录 | 通知及保护标识、计划版本、排程时间、最近失败原因 |

普通时间表按本地墙上时间显示；活动中的专注累计采用不会被手动改时直接扭曲的时间基准。记录时区信息，检测改时、时区变化与重启后重新核对计划、通知和限制，发现异常保留记录并提示检查。第一版不承诺抵御学生改变系统时间。

录音默认保存在应用本机目录，可单独删除；系统授权令牌使用平台支持的保存方式。第一版无注册、无广告、无第三方行为追踪；不使用摄像头或麦克风持续监督。数据删除需明确确认，并保留先撤销本应用限制、取消通知、再清理本机数据的顺序。限制解除失败时保留必要的恢复信息并提示处理，不静默清空。

## 9 验收用例

| 编号 | 输入或操作 | 预期结果 |
| --- | --- | --- |
| A01 | 创建四项示例计划 | 今日时间轴按时间排序，保留全部自由空档 |
| A02 | 给 10:00–12:00 语文预习添加 11:00–12:30 的另一项 | 提示冲突，不静默覆盖或保存重叠 |
| A03 | 10:20 开始语文预习 | 显示剩余 100 分钟，结束时间仍为 12:00 |
| A04 | 10:40 点击休息，10:45 自动恢复统计 | 专注累计扣除 5 分钟，无需再次点击，计划倒计时继续、12:00 结束 |
| A05 | 11:30 提前完成 | 记录完成、取消本项结束询问，午饭仍在 12:30；限制默认维持到 12:00 |
| A06 | 12:00 延长 10 分钟 | 结束改为 12:10，提醒及保护安排同步更新，午饭保持原时间 |
| A07 | 12:00 要求延长 40 分钟 | 提示与 12:30 午饭冲突，未经确认不顺延后续计划 |
| A08 | 12:00 未回应结束询问 | 学习保持未确认，12:30 午饭仍提醒，不累计超时专注 |
| A09 | 午饭或游戏时段结束 | 只提示结束，不自动记为完成的学习任务 |
| A10 | 15:40 启动计满 140 分钟的考试 | 预告 18:00 结束，检查冲突并确认保护更新后启动 |
| A11 | 活动中切后台、锁屏、重开 | 恢复正确剩余时间与专注记录；提醒行为符合系统授权 |
| A12 | 修改或删除未来任务 | 旧提醒取消，新提醒不重复；对应保护重新计算 |
| A13 | 通知权限拒绝，保护授权拒绝 | 计划仍可使用，明确显示提醒和限制未启用 |
| A14 | 学习段相邻或保护规则被修改 | 不在相邻学习段间误解锁，失败可见且无遗留屏蔽 |
| A15 | 学生尝试把生效中的学习任务改为娱乐 | 要求家长确认，不能直接释放限制 |
| A16 | 误点完成后撤销 | 恢复任务结果并按当前时间重算提醒，不虚增专注时长 |
| A17 | 修改每周重复任务的单次实例 | 只修改该次，其他实例和过去记录保持 |
| A18 | 使用大字体、VoiceOver、减少动态效果 | 任务、时间和按钮可读可操作，宠物动画可减弱 |

A01 至 A18 是行为验收规格。计时、冲突和状态转换使用自动化测试；通知与限制生命周期必须补充真实 iPad 测试，模拟状态不算设备能力验收。

## 10 开发顺序

| 阶段 | 工作内容 | 可验收产物 |
| --- | --- | --- |
| M0 技术验证 | 工具链、签名、授权、短时学习段限制及解除、通知和短录音 | 真机验证记录；确认能满足的限制范围与最低系统版本 |
| M1 可操作原型 | SwiftUI 工程、今日时间轴、表单、示例计划、本机保存 | 可创建和编辑当天安排，重开不丢失 |
| M2 执行闭环 | 固定时段计时、暂离、完成、延长、冲突与提醒 | 四项示例计划完整跑通，计时状态测试通过 |
| M3 家庭试用版 | 接入验证后的保护、家长设置、录音暗号、宠物和回顾 | 真实 iPad 上按计划提醒与保护，完成核心验收 |

M0 与不依赖设备权限的界面开发可交错推进。实际家庭试用前必须完成 M0；自动保护能力不足时，不能把界面原型标作完整可用的受限版本。
