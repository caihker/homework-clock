# v1.2.4 全面复查

2026-11-02（北京时间）。保留现有漫画界面、四项同名预选、GMT+8 时间和本机存储方式。

## 发现与修复

- 备份文件读取完成顺序可能与选择顺序不同，旧回调会清掉新读取的忙碌状态或弹出旧的恢复确认。增加读取代次检查、读取时禁止重复导入、关闭设置后作废读取，并在确认恢复前再检查代次。更新锁定时忽略选择及迟到结果。
- 多窗口保存冲突提示曾建议导出后重新打开，但导出只包含已保存状态，不包含录音草稿。提示明确草稿未保存、暂不要关闭、本地备份不含草稿，原草稿继续保留。
- 更新进入不可撤销的激活阶段后，原来的准备超时会恢复旧页面。现保持冻结，观察精确绑定的新版 worker；激活完成自动导航，失败变为 redundant 时恢复，准备阶段仍有45秒超时。激活信息缓存被回收，或状态事件、claim、广播丢失时，仍可通过绑定 worker 的 activated 状态完成导航。
