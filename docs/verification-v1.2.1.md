# v1.2.1 陪伴尺寸与作业统计验收

日期：2026-11-01，北京时间。

## 改动

- 原版乌龟大小保留。测量原版和立体版每个动画全部帧的 alpha 联合边界，使用 CSS 等比缩放与偏移，让对应状态的可见最大边及中心一致，解决透明留白使立体版显小的问题。选择卡以原版静态图为参考，运行中以对应原版动画为参考；减少动态效果时使用各自静态图。
- 保留 WebP 原文件及动画帧；方向变换最外层镜像，调头时偏移同步镜像，保持进度与触控按钮布局。素材比例不同，以最大边匹配，不拉伸形象。
- 家庭小设置的陪伴页顶部显示当前所查看日期的作业完成数量、完成率和剩余数量。仅 type=study，completed=true 才计完成，生活娱乐、列表筛选和已到截止时间不改变完成口径。空日显示 0/0、完成率「—」，进度可访问值为 0；日期标签按真实 GMT+8 的今天判断。
- 调整间距，固定保存区域保留。进入设置分类时回到内容顶部，优先看到统计。

## 验证

- 178 项自动测试、语法与离线资源清单检查通过。新增 7 项完成统计测试和 2 项可见尺寸几何测试，覆盖完成/撤销、日期、空态、原版回退、各状态边界和静态匹配。
- 独立量化六种动画与静态素材，确认变换后的可见边界仍在图框中；原版变换为单位矩阵，不改变其大小。
- 独立执行 app 的实际 render、完成、撤销、日期切换和复制 handler：筛选不影响统计，复制后的新日完成状态重置，保存恢复结果一致。
- 浏览器实测：2/2→100%，撤销数学后1/2→50%，生活或娱乐完成不改变学习统计；次日空态0/0及正确日期；回到今天恢复50%。完成专注后的统计升为100%，刷新仍保留完成记录及立体选择。
- 立体行走右/左、休息和庆祝实际使用对应素材及缩放参数，点击调头与原计划截止正常；选择卡两形象可见大小相当。
- 1194×834 横屏及 834×1194 竖屏检查通过，竖屏无横向溢出；横屏同时显示统计、两选项及保存按钮。
- 本机旧验收构建可经「检查更新 → 立即更新」切换，已保存形象与完成记录保留。停止预览源站后重开，100%统计及立体选择仍保留并可离线读取。

全部浏览器数据均为独立本机预览来源的示例计划，未操作真实 iPad 数据。最终离线版本 `09f48df16d46e1f631b3`，76 项资源、约17.6 MiB。发布标识见 `releases/published-v1.2.1.json`。
