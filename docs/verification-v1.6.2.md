# v1.6.2 记事移入左侧当前安排

2026-11-14（北京时间）。调整首页信息布局，让左侧卡片在内容多时不再空置，并放大记事字号。

## 变化

- 记事区从右侧「今日安排」面板移到左侧「当前安排」卡片下半部分：
  - 顺序：当前任务/计时/开始按钮 → 记事 → 陪伴形象。
  - 右侧时间轴只保留安排、回顾与底部操作，不再被记事撑长。
  - 左侧卡片在右侧安排较多时由记事填入下半部分，不再只集中在顶部。
- 字号调整：
  - 记事标题：13 → 15px；正文：13 → 14px；空态：12 → 13px。
  - iPad/横屏（≥700px）：记事标题与正文统一到 18px，与安排、按钮的字号一致；行距、分隔线、删除按钮间距同步放大。
- 竖屏平板的两栏当前卡片中，记事横跨两栏（`grid-column: 1 / -1`），避免被挤进半栏。
- 记事交互不变：点「加一条」、编辑、删除、备份包含记事、复制这一天复制记事。
