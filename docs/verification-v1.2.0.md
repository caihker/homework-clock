# v1.2.0 一键更新验收

日期：2026-11-01，北京时间。目标：新版资源准备完成后点一次更新，无需每次手动关闭所有窗口，并保留本机计划和录音。

## 实现与保护

- 等待中的 Worker 必须验证整份离线资源完整，才接受显式的「立即更新」。安装本身不自动跳过等待。
- 所有同范围窗口通过 PREPARE 检查，冻结输入、计时写入和动画；仅发起窗口 COMMIT 一次。其他窗口不回写陈旧内存。
- 录音授权/录音/处理、未保存文字/录音/陪伴设置、安排编辑、输入法组合、备份恢复和未处理确认均阻止此次更新；存储失败不切换。
- 最后检查窗口成员和缓存完整，20 秒事务总截止；成功后启用目标版本，各已确认窗口自动重开。仅匹配本次 Worker、版本和事务的激活才重开，不因首次安装或任意 controllerchange 循环刷新。
- 普通保存也检查上次存储快照；取消后干净旧页采用其他窗口已保存的新数据，再恢复自动保存。未保存草稿仍留在原窗口。
- 更新中的新页面读取短期启动屏障，先冻结、不写回本机数据，等待匹配事务结束后安全重开。未知旧窗口或无响应窗口使更新取消，不强制丢弃它的内容。
- 显式切换期间保留旧资源快照，不清 localStorage 中的计划或声音。

## 本轮发现并修复

1. 取消更新后旧窗口下一次自动保存可能覆盖新数据：增加保存快照检查和取消后的最新数据采用，独立 VM 原样执行 app 函数确认已修复。
2. 意图写入过程中新增窗口可绕过原成员检查：将最终成员检查后移，增加共享启动屏障与总截止，回归确认不会迟到激活。
3. Safari 直接拒绝 localStorage getter 时，helper 入参求值可抛错：使用委托存储引用，让异常进入受控失败，保留旧数据和草稿。
4. 取消消息可能覆盖具体错误原因：将同一可操作提示同时返回给发起者与各窗口。

## 验证结果

- 全部 169 项自动测试通过；语法与离线清单检查通过。最终离线清单 74 项、17.6 MiB，build `515fe4040d19d5a8a3b7`。
- 独立只读审查复现并复验上述取消后回写、写入时开新窗口、存储 getter 拒绝等边界，未发现新增阻塞。
- 独立本机浏览器来源使用 4 项合成计划、7 段内置测试音频、立体陪伴和正在休息的会话。未访问真实麦克风或 iPad 数据。
- 最终代码验证：另一窗口先保存新暗号再保留未保存提醒，更新正确拒绝并显示来源；原发起页采用新暗号，草稿原样保留；取消后再次保存不覆写已存数据。
- 保存草稿后，三个窗口保持打开，单次「立即更新」全部自动切换至候选新版。七段录音 SHA-256、计划名称、陪伴选择、paused 状态、休息结束时间和最终计划截止，在三个窗口更新前后完全一致。
- 停止预览源站后重开，离线页面正常且上述诊断数据保持一致。
- A/B/C 及最终 D/E 测试版本位于临时目录，只在内容标记及 QA 诊断上不同；QA 页面、数据与诊断模块不进入发布包。

## 迁移和验证边界

v1.1.3 及更早页面没有一键入口或窗口协议，首次启用 v1.2.0 仍需按旧方式重开一次。之后可使用一键更新。后台冻结或旧窗口不能响应时会保留当前版本，提示处理后重试。

浏览器验收使用桌面内置浏览器，未直接操作真实 iPad。发布成功由原私有站点部署服务确认，发布标识见 `releases/published-v1.2.0.json`。
