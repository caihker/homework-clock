# v1.6.0 阶段 5 第一批：常用计划模板、导出到日历、冲突详情

2026-11-14（北京时间）。阶段 5 开始，本批补上「每天重复安排」的两个低成本缺口：可复用模板与系统日历外化；同时把冲突提示具体到重叠项。每周重复生成尚未做，列为下一批。

## 完成内容

### 常用计划模板（5-A 部分）

- 数据：`state.templates` 新增 `{ id, title, type, duration }`，时长 10–600 分钟；旧状态/旧备份缺少该字段时默认为空。
- 新增安排/编辑安排：
  - 「存为常用计划」保存当前标题、类型和时长（开始到结束），重复项不重复添加。
  - 模板以 chip 显示在预设「学习/吃饭/运动/游戏」下方；点击套用标题/类型，并按当前开始时间 + 模板时长设置结束时间，超过 21:50 自动截到 21:50。
- 本机设置新增「常用计划」管理：查看类型、时长与删除；删除不影响已有安排。
- 备份：模板随备份导出/恢复；无效、重复 id 或超范围时长会令整份备份拒绝，而不是静默丢弃。
- 「重新体验示例」保留模板（与家庭设置一致）。

### 导出到系统日历（5-B 第一路线）

- 本机设置新增「导出到日历」：按当前选中日期生成 `.ics` 并下载，无需服务器与网络。
- 内容：`VCALENDAR` + 每项 `VEVENT`；`DTSTART/DTEND;TZID=Asia/Shanghai`，含标题、类型/科目说明、稳定 UID；按开始时间排序。
- 文本按 iCalendar 规则转义（反斜杠、逗号、分号、换行）；结束时间不晚于开始或非 `HH:MM` 的记录被跳过。
- 导入后为一次性日历事件，不会与 App 内后续修改自动同步；这是当前「提醒外化」的明确边界。
- Web Push/服务端方案未引入，继续遵守零后端约束。

### 冲突提示（5-C）

- `validateTask()` 冲突时找出具体重叠项，提示改为：`这个时间和“语文预习”（10:00–12:00）重叠了，换个时间试试。`
- 相邻安排、编辑自身、跨日期不冲突的既有规则不变。
