# v1.6.3 记事下方的「龟言龟语」

2026-11-14（北京时间）。在左侧当前安排卡片内新增随机励志短句区域，给孩子一点低压力鼓励。

## 变化

- 位置：记事下方、陪伴形象上方，顺序为 当前安排 → 记事 → 龟言龟语 → 小乌龟。
- 每次打开 App 随机选一条显示；点「换一句」立即换一条，并避免与当前句子重复。
- 内置 24 条短句，主题覆盖：
  - 开始与坚持：先开始、一次只做一件事
  - 错题与求助：错题是提醒、不会就问
  - 休息与身体：累了就休息、先照顾身体
  - 结果与节奏：不急着被看见、计划可以调整
- 文案刻意不评判成绩、不催促、不制造比较。
- 无障碍：文本使用 `role="status"`，换句时读屏会播报；按钮有明确 `aria-label`。
- 字号与记事统一：桌面 14px、iPad 18px；浅色虚线卡片，和手绘风格一致。
