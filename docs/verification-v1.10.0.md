# v1.10.0 每周重复：到日期结束

2026-11-14（北京时间）。每周重复从固定次数扩展为「按次数 / 到日期」两种结束方式。

## 用法

- 勾选「每周重复」后，结束方式可选：
  - **按次数**：每个选中星期重复 4/8/12 次（原行为）。
  - **到日期**：重复到指定日期（含当天）；默认填开始后 8 周，可修改。
- 到日期模式按每个选中星期生成；开始日期之前不生成。
- 至少选择一个星期；日期早于开始、日期无效、生成超过 400 次都会拒绝保存并提示。
- 多星期、逐条冲突/时间窗校验、整组修改/删除继续适用。

## 边界

- 仍不支持真正的“无限重复”；超过 400 次会被拒绝（避免一次写入过多安排）。
- 结束日期包含当天；若选中星期的下一次 occurrence 已超过结束日期，则不会生成。
- 默认结束日期为开始后 56 天，可手动调整。
- 小屏横屏下表单需要滚动到底部保存。
