# v1.7.0 每周重复安排

2026-11-14（北京时间）。阶段 5 的每周重复先落地一个清晰、可备份的版本：一次生成未来 4/8/12 周的同一星期安排。

## 用法

- 新增安排时勾选「每周重复」，选择 4/8/12 周，保存后按所选日期所在星期生成每一次。
- 生成前逐周检查冲突与时间窗；任何一周冲突都会整体拒绝并指出日期，不会只写入一半。
- 每一次都是普通安排，可以单独完成、编辑、删除；编辑重复中的某一次时，表单会提示“只影响这一次”，并隐藏重复选项。
- 「复制到明天」「复制这一天」会移除重复标记，复制出的安排不会接回原重复组。
- `seriesId` 随备份导出/恢复，旧备份无该字段不受影响。

## 明确定义与边界

- 只支持同一星期重复；一次只能选 4/8/12 周，不支持多星期组合或无限重复。
- **「修改以后所有」尚未实现**：当前编辑/删除只影响单次；如需长期改作息，仍需逐次调整或重新创建重复组。
- 重复会生成具体安排（不是规则引擎），因此会占用相应存储；12 周最多 12 条，规模可控。
- 不支持“每两周”“工作日每天”等更复杂节奏。
