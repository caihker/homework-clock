# v1.8.0 每周重复：修改以后 / 删除以后

2026-11-14（北京时间）。在 v1.7.0 的每周重复基础上补齐整组操作。

## 新增

- 编辑重复中的某一次时，新增「同时修改以后的所有重复（未完成的）」：
  - 当前这次 + 之后所有未完成实例同步标题、类型、开始/结束时间、科目。
  - 已完成和过去的实例保持不变。
  - 每条实例单独做冲突与时间窗校验；任何一条失败，整组修改不写入并指出日期。
- 新增「删除以后所有重复」：
  - 从当前这次起删除该系列后续安排（含已完成实例），之前的保留。
  - 删除后可撤销恢复。
- 单次删除仍通过原有「删除安排」完成；系列编辑提示更新。
- 系列元数据 `seriesId` 继续随备份保存；复制安排不会串组。

## 边界

- 「以后」指当前实例日期及之后；过去和已完成的实例不批量修改。
- 「删除以后」包含后续已完成实例；如只想保留完成记录，可先单独撤销/调整。
- 仍不支持多星期组合、结束日期、无限重复或“每两周”；这些需要规则/例外数据模型。
- 系列目前是具体安排集合，不是可随时改规则的模板；大量重复会占用相应存储（12 周最多 12 条）。

## 后续建议

- 从设置页集中管理系列（查看、整体删除、规则编辑）。
- 真机验证批量修改后的备份恢复与跨设备迁移。
