# v1.4.0 阶段 3：信息架构、可信度与可用性

2026-11-06（北京时间）。本版对应 [分阶段优化方案](optimization-plan.md) 阶段 3，已完成两批：下一项、能力披露、草稿保护，以及时间标线、回顾归位、无障碍、演示时间入口、Toast、快速调整与截图基线。

## 第一批（已完成）

### 下一项

- 首页当前卡片在「开始专注」下方新增「下一项」：名称、开始时间、相对倒计时，点击打开该安排编辑。
- 时间轴给下一项加「下一项」标记，当前项加 `aria-current="step"`。
- 新增纯函数 `plan-view.nextTask()` 与 2 组单元测试。

### 能力披露

- 首页顶部常驻可展开说明「仅前台提醒 · 不限制其他 App」，说明锁屏/关闭应用不提醒、本版本不提供应用限制、数据只留本机。
- 设置「本机与备份」页同步一句说明。

### 设置草稿保护

- X、点击背景、Esc、「回到今天」四个关闭入口先检查未保存内容；有录音、开关、陪伴或家庭文字改动时先确认。
- 复用更新守卫的 `hasSettingsDraft()`；录音进行中也视为未保存。

## 第二批（已完成）

### 当前时间标线

- 查看今天时，时间轴按当前时间插入「现在 HH:mm」虚线标线；纯函数 `plan-view.nowMarkerIndex()` 计算插入位置并带测试。
- 未来日期或筛选状态不显示标线，避免误读。

### 当日回顾归位

- 设置「陪伴」页的作业完成统计与「本机」页学习记录合并到时间轴末尾的「今日回顾」折叠卡（完成数、专注分钟、完成率、剩余项）。
- 设置页不再重复展示统计，只保留开关与备份。

### 无障碍一日修

- 7 个弹窗补 `aria-labelledby`（任务、设置、演示时间、复制、确认、收尾、专注）。
- 筛选按钮增加 `aria-pressed`，渲染时同步激活状态。
- 主计时与专注计时加 `role="timer"` 与 `aria-live="off"`。
- 专注页静音按钮的图标与 `aria-label` 跟随声音开关。
- 空闲标签字号 9/8 → 12/11px，颜色改为正文色（对比度 3.44 → 5.8:1）。
- 装饰性调头乌龟移出 Tab 序（`tabindex="-1"`），仍可点击与读屏访问。

### 演示时间移入设置

- 顶栏只显示当前时间（不可点击），「家庭设置 → 本机」新增「演示时间」入口，避免误触终止计时。
- 顶栏时间文案与提示仍随演示/真实模式更新。

### 时间轴与反馈

- 「常用计划」伪导航按钮移除；空态文案改为「今天还没有安排」/「添加第一项」。
- Toast 上移到内容上方（78px + 安全区），非撤销态不拦截点击。
- 任务编辑弹窗新增「提前 10 分钟 / 延后 10 分钟 / 复制到明天」：`plan-view.shiftSlot()` 校验 08:00–21:50 边界与冲突，复制到次日并校验冲突。
