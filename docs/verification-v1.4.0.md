# v1.4.0 阶段 3 第一批：下一项、能力披露、草稿保护

2026-11-06（北京时间）。本版开始阶段 3（信息架构与可信度），先处理设计文档 P0 验收里的“下一项”、信任层面的能力披露和最容易丢数据的设置草稿。阶段 3 其余条目继续做。

## 完成内容

### 下一项

- 首页当前卡片在「开始专注」下方新增「下一项」：显示名称、开始时间、相对倒计时（如“12:30 · 43 分钟后”），点击直接打开该安排的编辑。
- 时间轴给下一项加「下一项」标记，当前项加 `aria-current="step"`。
- 新增纯函数 `plan-view.nextTask(tasks, currentId, atMs)`：按开始时间排序，取当前项之后第一个未完成且尚未开始的安排；无下一项时隐藏。带 2 组单元测试（排序、跳过已完成、无效日期、不推进时钟、不修改输入）。
- 设计文档 §1.3「首页无需进入详情即可看到当前任务、结束时间和下一项」达成。

### 能力披露

- 首页顶部常驻一条可展开说明「仅前台提醒 · 不限制其他 App」，展开后说明关掉应用/锁屏不会提醒、本版本不提供应用限制、数据只留本机。
- 设置「本机与备份」页同步一句说明，避免备份说明被误读为提醒/限制能力。
- 不依赖授权或系统状态查询，属于静态事实披露，符合设计文档 §1.3/§5 的“如实显示能力状态”。

### 设置草稿保护

- 关闭家庭设置的四个入口都先检查草稿：右上角 X、点击弹窗背景、Esc、设置里的「回到今天」。
- 有未保存的录音、开关、陪伴选择或家庭文字改动时，弹出「放弃未保存的设置？」确认；取消则留在设置页。
- 录音进行中也视为未保存内容。保存成功直接关闭，不额外打扰。
- 复用更新守卫已有的 `hasSettingsDraft()`，与一键更新的草稿判断保持一致。
