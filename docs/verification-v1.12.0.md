# v1.12.0 重复安排集中管理

2026-11-19（北京时间）。在「本机设置」中集中查看和管理所有每周重复系列，不必逐天翻时间轴。

## 新增

- 「本机 → 重复安排」按 `seriesId` 分组展示：
  - 标题、星期（如 周四）、时间、总次数、下一次日期。
  - 无重复安排时显示空态；已结束的系列显示“已结束”。
- 「查看」：关闭设置，跳到下一次（没有下一次则最后一天），并直接打开该次安排的编辑框。
- 「删除整组」：删除该系列全部实例（含已完成和过去），有确认与撤销；若系列中有正在计时的任务，会先归档。
- 按钮带出系列标题的读屏标签；行布局在 iPad 字号下保持可读。
- 分组/排序由纯函数 `seriesGroups(tasks, today)` 完成：按下一次日期排序，星期按周一至周日排列。

## 边界

- 管理页只做查看/进入编辑/整组删除；重命名或改整个系列规则仍通过“打开某一次 → 同时修改以后”完成。
- “查看”优先下一次；全部结束后打开最后一次。
- 删除整组包含已完成/过去实例；撤销会恢复整个系列。
- 未在真机 iPad 上验证长列表滚动与触控。
