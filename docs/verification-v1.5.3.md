# v1.5.3 阶段 4 第三批：陪伴与计时视图拆分

2026-11-14（北京时间）。本版继续阶段 4（可维护性），把陪伴/乌龟与计时渲染从 `app.mjs` 拆出；不改变产品行为。

## 完成内容

### `mascot-view.mjs`

- 抽出陪伴形象渲染：情绪与动画帧选择、乌龟进度与调头、完成庆祝、离线/加载失败静态帧回退、设置页预览、`reducedMotion`/`visibilitychange`/`online` 监听。
- 通过工厂注入 `$`/`$$`、任务时间辅助、状态读取器、锁定与当前任务读取器；`turtleTrips` 与庆祝状态移入模块。
- `app.mjs` 不再直接维护乌龟状态；完成任务、撤销、备份恢复通过 `celebrate()/reset()` 调用。

### `clock-view.mjs`

- 抽出 `updateClocks()`：首页剩余时间/距离开始、会话徽标、顶部时间模式、专注页大字与状态、静音图标、当日专注分钟统计、乌龟进度同步。
- 依赖注入计时/会话辅助、格式化函数、陪伴视图与状态读取器；`app.mjs` 保留一个薄包装 `updateClocks()` 供现有调用点使用。
- 未改变任何 HTML 结构或文案。
