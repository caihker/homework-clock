## 配置情景语音

在「家庭小设置 → 声音 → 情景语音」选择一个状态，点击「录制」，结束后用「试听」检查，再点击外层「保存设置」统一生效。每段最长 8 秒。录音、转换和麦克风授权等待期间不能保存或切换状态；关闭设置会放弃未保存的草稿。开工暗号与文字收在「开工文字（可选）」内，备份、学习记录和示例入口放在「本机」页。

「恢复默认」只清除对应场景的草稿录音，其他场景不受影响，点击「保存设置」后生效。未录音的状态使用内置小乌龟语音；手动开工未录音且家庭文字已自定义时，仍由设备朗读家庭文字。

录音保持在本机，所有情景的录音都包含在备份里。优先请求较低录音码率来减少占用；如设备存储不可用或容量不足，保留原设置并让当前草稿继续可编辑，不会只保存其中一部分。

v1.0.2：顶部显示北京时间的今天及星期，右侧计划日期独立切换，查看过去的计划不会把顶部的今天改成历史日期。左右日期箭头支持跨月、跨年双向切换；日期选择器的触控范围限制在中间区域，避免遮住箭头。

## iPad 首次启用

1. 使用 Safari 打开提供此版本的 **HTTPS 网址**。本地文件夹或 ZIP 不能直接安装成 PWA。
2. 在「家庭小设置 → 本机」确认「离线准备完成」。首次会完整缓存当前使用的字体、图标、动画和全部固定语音，不下载旧版图标及旧动画。
3. Safari「共享 → 添加到主屏幕」，如有「作为网页 App 打开」，打开该选项。
4. **保持联网，从主屏图标首次打开**，再次确认「离线准备完成」，再尝试断网使用。Safari 和主屏版本不应假定共享数据或缓存。
5. 首次点击语音试听以允许声音播放。麦克风录音需授权，实际 iPad 的录音及音频兼容性仍需真机确认。

日常无需电脑常开、账号、推送服务或云数据库。首次安装、更新、换设备或缓存被清除后，仍需可用的 HTTPS 网址。网站必须允许同源静态资源和 Service Worker 正常加载。

修改本地文件不会自动更新线上站点；已发布版本以项目根目录的 `releases/` 记录为准。

## 本机数据与备份

计划、完成状态、专注历史、家庭设置与录音自动保存在当前浏览器/主屏版本的本机存储中。

- 「家庭小设置 → 本机与备份 → 导出备份」生成一个 JSON 文件，请存到 iPad「文件」App。只包含已保存的家庭设置；刚录好的声音需先保存设置。
- 「恢复备份」读取并校验文件，显示安排/记录数量，再由你确认替换。格式无效或存储失败时保留原数据。
- 备份包含当前已记录的专注时间，扣除休息并限制在计划结束前；恢复后保留记录但不自动开始计时，避免重复补时。
- Safari 转主屏版本前先导出，再在主屏版本恢复。换设备或清理站点数据前也应先备份。
- 单份备份上限 16 MiB，每段家庭录音上限 1 MiB，每段最长 8 秒。数据留在本机，不会上传到业务服务器。

## 现有功能

- 学习、生活、娱乐计划增删改，按日期查看、筛选、常用模板、整天复制、时间冲突检查。
- 开始时间选择为 08:00–21:00，结束时间至 21:50，分钟步长 10；已有旧时间未重新选择时保留。
- 任务支持提前手动开始、完成撤销、延长 10 分钟；计划结束时间固定，晚开始不自动顺延。
- 休息 5 分钟只扣专注统计，倒计时继续；到点自动恢复统计，无需再次点击，回来时按时间戳核对。
- 完成庆祝、进度条乌龟、家庭暗号、固定卡通语音、设备文字朗读和家人录音。
- 固定 MP3 及已有录音可离线播放；自定义文字的离线朗读取决于设备提供的音色。
- 演示时间仍可手动选择。旧演示版首次升级切回真实时间，已有计划和记录保留。

## 运行和验证

无需安装项目依赖。需要 Node.js 20.11 或更新版本。

```sh
npm run build
npm test
npm run check
npm start
```

打开 `http://localhost:4173`。localhost 可测试 Service Worker；iPad 不能把电脑的 localhost 当作安装网址，正式首次启用需 HTTPS。

预览服务器默认只监听本机。更换端口使用 `PORT=4174 npm start`；确有局域网预览需要时可自行指定 HOST（普通 HTTP 局域网地址不满足离线安装的安全上下文要求）。

修改任何 `dist/` 文件后必须重跑 `npm run build`，生成带 SHA-256 资源校验的 `dist/sw.js`，再整体部署 `dist/`。`npm run check` 会拒绝过期清单。

资源下载完整后才完成离线安装；中断后显示失败资源及原因，点击「继续准备」会重新启动安装并保留已校验完成的资源。下载、读取和缓存写入都有等待上限，失败不影响已有完整版本。普通安装继续等待窗口关闭；只有点击「立即更新」且各窗口检查通过后才切换，保留计时的时间戳。缓存清理仅涉及作业时钟自身的旧资源，不清理计划数据。

v1.0.1 修复「下载到 58/73 项停止、重试一直加载」：将离线首页直接包含在程序包中，避免私有托管对 HTML 的动态改写影响校验；修复首次安装失败后空注册记录未重新启动安装的问题。更新后先关闭所有作业时钟窗口，再联网从原入口重新打开。无需清理站点数据或删除主屏图标。

## 主要文件

- `dist/app.mjs`：计划、计时、设置和备份 UI。
- `dist/plan-view.mjs`：统一进度、新计划时间建议、多日倒计时；`reminder-events.mjs`：前台提醒事件与去重。
- `dist/scene-voices.mjs`：七种状态与录音迁移、选择；`scene-voice-settings.mjs` 和 CSS：录音草稿、试听及恢复默认。
- `dist/audio-format.mjs`：录音 MIME 和内嵌音频统一解析，兼容 Safari 格式标记。
- `dist/backup.mjs`：备份格式校验、快照和恢复；`tests/backup.test.mjs` 验证无损往返及错误文件拒绝。
- `dist/pwa.mjs`、`pwa.css`：设置内离线状态、重试和主屏说明。
- `dist/offline-client.mjs`：安装状态、超时、重新注册、失败重试及更新协调。
- `dist/update-guard.mjs`、`update-session.mjs`、`update-storage.mjs`：更新前草稿检查、窗口冻结/保存/重开、存储冲突和新窗口启动屏障。
- `dist/manifest.webmanifest`、`assets/pwa/`：主屏配置与图标。
- `scripts/build-offline.mjs`、`service-worker.template.js`：完整资源缓存、更新隔离及 Safari 音频 Range；`tests/offline.test.mjs` 覆盖离线、失败和更新。
- `dist/assets/category-flat-byg/`：最新蓝黄绿扁平分类图标；设计源位于上级 `design-assets/turtle-category-icons-flat-byg/`。

## 素材与边界

字体、动画、图标和固定语音均随程序保存，无运行时第三方字体或语音服务请求。圆体/漫画字体源及 OFL 许可见 `dist/assets/fonts/`；语音为预生成 MP3，重建脚本见 `scripts/generate-voice-pack.py`。角色和分类图标源保留于上级设计目录。

本版不包括后台/锁屏通知、专注限制、跨设备同步、每周重复或拖动调整。PWA 缓存不是永久安装保证，浏览器数据清理或设备空间回收后可能需要重新联网准备；请定期导出备份。
