# 已退役的运行时素材（仅存档）

这些目录曾是 `demo/dist/assets/` 下的运行时副本，但当前程序已不再引用，也不进入离线清单。为避免它们随私有站点部署、增加 iPad 下载与构建负担，已从 `demo/dist` 移到本目录存档。

- `category-3d-v2/`：立体分类图标迭代稿。
- `category-flat-v1/`：扁平分类图标第一版。
- `motion/`：早期乌龟动画帧。

当前程序使用 `demo/dist/assets/category-flat-byg/`、`assets/motion-original-v2/` 与 `assets/motion-solid/`。恢复这些素材前先确认引用与离线清单，再放回 `demo/dist` 并运行 `npm run build`。
